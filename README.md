# Blood pressure during emergency department care for epistaxis

This repository contains the analysis code for a retrospective two-center cohort study of the ED course of elevated blood pressure, subsequent outpatient hypertension, and early return for epistaxis. The primary comparison was persistently elevated versus transiently elevated BP for ED return for epistaxis within seven days. Treatment comparisons were descriptive or exploratory. The supplementary bleeding-severity models were post hoc.

## Data access

Obtain access to the confirmed study releases, MC-MED v1.0.1, MIMIC-IV-ED v2.2 and MIMIC-IV v3.1, through their PhysioNet projects. Obtain credentialed access for each release and complete the training and data-use requirements applicable to it. Use the archive layout below. [MC-MED v1.0.1](https://physionet.org/content/mc-med/1.0.1/) · [MIMIC-IV-ED v2.2](https://physionet.org/content/mimic-iv-ed/2.2/) · [MIMIC-IV v3.1](https://physionet.org/content/mimiciv/3.1/)

| Project-relative input | Expected files or archive members |
| --- | --- |
| `mc-med/` | `visits.csv`, `numerics.csv`, `orders.csv`, `meds.csv`, `pmh.csv`, `labs.csv`, and `rads.csv` |
| `mimic-iv-ed_2.2.zip` | `mimic-iv-ed/README.txt`, `mimic-iv-ed/SHA256SUMS.txt`, and the `diagnosis`, `edstays`, `medrecon`, `pyxis`, `triage`, and `vitalsign` tables as `.csv.gz` within `mimic-iv-ed/ed/` |
| `mimic-iv_3.1.zip` | `mimic-iv-3.1/SHA256SUMS.txt` and the `admissions`, `d_icd_diagnoses`, `d_icd_procedures`, `diagnoses_icd`, `omr`, `patients`, and `procedures_icd` tables as `.csv.gz` within `mimic-iv-3.1/hosp/` |

Run the pipeline in an access-controlled project directory. The extraction scripts check members against the archived SHA-256 manifests and preserve existing source files. The P8 hospital extraction is a separate opt-in step. DuckDB streams the large laboratory file and keeps only measurements relevant to the analytic cohort. Source data and generated restricted intermediates remain inside the authorized directory. ## Environment and run order

See [ENVIRONMENT.md](ENVIRONMENT.md) for the tested Windows, Python, R, and library versions. Create `.venv` and `.venv/R/library` in the working project. Put `Rscript` on `PATH` and make Arial available for the submission figures. The commands below are run from the project root.

```powershell
$studyPython = '.\.venv\Scripts\python.exe'
& $studyPython -B code/01_p0_audit.py
& $studyPython -B code/02_p1_setup.py
& $studyPython -B code/07_p6_reproduce.py --stage prior

& $studyPython -B code/07_p6_lmm.py
& $studyPython -B code/07_p6_overlap.py
& $studyPython -B code/07_p6_tables.py
& $studyPython -B code/07_p6_figures.py
& $studyPython -B code/07_p6_ledger.py

& $studyPython -B code/02_p1_setup.py --include-p8-labs
& $studyPython -B code/09_p8_severity.py --audit-pyxis
& $studyPython -B code/09_p8_severity.py
& $studyPython -B code/08_p8_figures.py
& $studyPython -B code/08_p8_tables.py --deviations docs/deviations_en.md
```

On a fresh setup, the first two commands create the input views and verify the original archive members. The P1–P5 replay checks the existing members before recreating the cohorts and analyses. It records changes against any prior aggregate outputs in `outputs/reproducibility/`. P8 leaves the primary regression outputs intact and generates separate post hoc result and quality-control tables. Figure and table assembly uses reviewed estimates already generated by the earlier stages.

The supplementary mention map requires the author-held tagged main manuscript at `manuscript/draft_v2_OHNS_tagged.md` or at the path passed to `08_p8_tables.py --manuscript-v2`. The supplementary numeric check can be rerun in the authorized writing workspace with `code/08_p8_ledger.py --check-only`. It expects the tagged `manuscript/supplement/supplement_v1.md`, its matching author-workspace `outputs/key_numbers.csv`, and the complete author-workspace `outputs/env.txt` including the recorded `nlme`, `lme4`, and `lmerTest` versions. The author-workspace files are held with the submission materials.
